# Ku v1.1.0

2026-11-21 · Alpha

本版本加入原生代码记忆存储、编译检查与格式化工具，并完成 Windows、Linux、macOS SDK 的打包和安装后验证。

## 新增

- `dao-ku --check` 验证源码，`--fmt` 输出格式化结果。
- `dao-ku --store` 编译并保存带 identity/version 的模块，`dao-module verify|run` 校验和执行代码记忆。
- ModuleStore 保存模块、源码校验和和父版本记录。同一版本的内容和来源保持不可变，父记录须预先存在。
- 单写入者 OS 锁、manifest 最后发布及相同输入重试恢复。重叠写入返回忙碌错误。
- Python MemoryHost 对接 `存` / `取` / `忘`，CodeMemory 提供原生存储的 Python 适配器。
- 三平台 SDK ZIP 和 SHA-256 校验文件。Windows 包附带 LLVM C++ 运行库与许可，SDK 内的 Python 绑定可发现安装目录。

## 修复

- 保存中断后缺失 manifest 的假成功、损坏 JSON 校验、派生保存重复父字段、来源冲突和临时源码竞争。
- 中文函数参数推断、无宿主回调时 Runtime 关闭，以及 GCC 15 下自举 Context 初始化告警。
- 安装后的编译器优先使用包内自举源码，Unix 可执行工具使用相对库搜索路径。

## 下载与使用

选择与系统和架构对应的 `Ku-1.1.0-<系统>-<架构>.zip`，解压后使用 `bin` 中的 `dao-ku` 和 `dao-module`。
Windows 附件为 x64，Linux/macOS 附件的架构以文件名为准。包名中的 Darwin 表示 macOS。
Linux/macOS 构建环境随对应 GitHub Actions runner 提供，系统 C++ 运行库须可用。

SDK 版本、Python 项目元数据和 Rust 绑定版本统一为 `1.1.0`，二进制模块保持 v2/ABI10 与已有 v1/ABI9 兼容路径。
标准库 identity 的精确版本继续为 `1.0.0`。Python/MCP 源码示例与完整文档可通过本标签的源码归档获取。

## 验证与边界

- 功能 CTest 与 Python 集成测试通过，覆盖模块验证、自举一致性、存储契约、绑定和工具命令。
- 三平台 ZIP 解压后在独立目录验证编译、检查、格式化、保存、校验、执行和 Python C ABI 调用。
- AOT 性能阈值按现有 CI 策略单独运行。全量旧链测试、fuzz、soak 和断电持久性未在本次发布中验证。
- Record / Schema / Result、完整类型系统、Model Capability ABI 和原生长期运行网关继续开发。
